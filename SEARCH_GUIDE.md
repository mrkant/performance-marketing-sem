# Search Guide

The internal search is static and works on GitHub Pages or a future custom domain.

## Files

- `search.html`
- `search-data.json`
- `assets/js/main.js`

## How to edit search results

Open `search-data.json` and add or update an item with:

- id
- title
- url
- type
- status
- description
- excerpt
- keywords
- tags
- relatedCompanies
- relatedSkills
- priority
- contentSummary

Use relative URLs such as `services.html` or `journey.html#ibm`.
