# Shashi Kant Website

A fresh GitHub Pages-ready website with a premium dark Bento Grid homepage, animated journey preview, service matcher, selected work pages and ecommerce-style internal search.

## Main files

- `index.html`
- `journey.html`
- `search.html`
- `search-data.json`
- `assets/css/style.css`
- `assets/js/main.js`

## Before public launch

Replace:

- `https://your-domain.com`
- `your-public-email@example.com`
- `https://www.linkedin.com/in/your-linkedin-url`

Upload all files and folders to the repository root.
